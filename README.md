# vk_recommendations_systems

Данный кейс находится в архиве, решения по этому кейсу больше не принимаются. Вы можете выбрать любой из актуальных проектов на сайте https://education.vk.company/education_projects.

В современных рекомендательных системах всё чаще используются гибридные модели, сочетающие коллаборативную фильтрацию и контентные признаки объектов. Однако влияние различных типов контентных эмбеддингов (текстовых, визуальных, мультимодальных) на итоговое качество рекомендаций остаётся недостаточно изученным.

В рамках проекта студентам предлагается:

Реализовать несколько алгоритмов коллаборативной фильтрации на открытых датасетах

Добавить к ним различные виды контентных эмбеддингов (предоставляемые датасетами или извлекаемые заранее обученными моделями)

Оценить, как добавление тех или иных эмбеддингов влияет на точность рекомендаций, устойчивость модели и качество ранжирования

Сформулировать выводы о том, какие виды контентных сигналов наиболее полезны для улучшения качества рекомендаций в разных сценариях

Материалы для выполнения проекта:
Открытый датасет VK-LSVD: https://huggingface.co/datasets/deepvk/VK-LSVD  

Алгоритм выполнения проекта:
Реализация нескольких алгоритмов коллаборативной фильтрации на открытых датасетах, добавление контентных эмбеддингов, сравнение полученных моделей

Какие навыки и компетенции нужны для выполнения:
Базовые знания принципов работы рекомендательных систем


Какой результат хотим получить:
Сравнение влияния различных типов контентных эмбеддингов на рекомендации

В каком виде загрузить результат на платформу:
Код и отчёт с метриками в формате docx. или pptx.

Критерии выбора лучших работ:
Качество оформления отчёта и показатели метрик
