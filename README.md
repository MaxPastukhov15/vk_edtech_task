# vk_edtech

## Цель проекта
Разработать модель сегментации учителей на основе логов их активности на EdTech-платформе. Результаты модели должны помочь персонализировать личный кабинет, настроить таргетированные коммуникации и повысить ключевые продуктовые метрики: MAU, количество активных дней в месяц и удержание пользователей.

## Описание проекта
EdTech-платформой пользуются разные группы учителей. Одни заходят на неё ежедневно, чтобы выдавать и проверять домашние задания. Другие используют платформу как цифровую библиотеку для подготовки очных уроков. Третьи активно работают с интерактивными инструментами: проводят вебинары, запускают онлайн-трансляции и используют дополнительные сервисы платформы.

Продуктовой команде нужно лучше понимать эти различия. Для этого необходимо выделить устойчивые поведенческие сегменты учителей и описать, чем они отличаются друг от друга с точки зрения продуктового поведения.

Студентам предоставляется выгрузка активности пользователей в формате CSV. На её основе нужно провести разведочный анализ данных, сформировать продуктовые метрики для каждого учителя, применить алгоритмы кластеризации без учителя и подготовить бизнес-рекомендации по адаптации продукта под каждый сегмент.

Аналитическая функциональность решения должна включать:
- Предобработку данных — фильтрацию логов, обработку пропусков, исключение аномальной активности, тестовых аккаунтов и парсеров
- Генерацию признаков — расчёт продуктовых метрик вовлечённости на основе частоты и регулярности использования ключевых модулей платформы
- Кластеризацию — применение алгоритмов K-Means и DBSCAN на базе библиотеки scikit-learn
- Валидацию качества — обоснование оптимального количества кластеров с помощью метода локтя и силуэтного коэффициента
- Профилирование сегментов — визуализацию различий между группами и описание каждого сегмента на языке бизнеса
## Вам предстоит изучить
- Основы продуктового анализа и ключевые продуктовые метрики
- Методы обработки, агрегации и очистки логов с помощью pandas
- Алгоритмы машинного обучения для кластеризации — K-Means и DBSCAN
- Способы оценки качества кластеризации
- Подходы к переводу аналитических результатов в продуктовые и бизнес-рекомендации

- Интегрировать элементы RFM-анализа для оценки лояльности и активности сегментов
- Предложить алгоритм классификации, который будет автоматически относить новых учителей к одному из выделенных сегментов
## Алгоритм выполнения проекта
- Скачайте CSV-выгрузки и проведите первичный EDA: оцените объём и типы данных, пропуски, дубликаты и аномалии
- Очистите данные: отфильтруйте нерелевантные события, тестовые аккаунты, подозрительную или аномальную активность
- Сформируйте матрицу «пользователь — продуктовые метрики» (частота входов, регулярность использования, активность по разделам платформы, работа с ключевыми модулями)
- Подготовьте признаки для моделирования: выполните стандартизацию и масштабирование данных
- Проведите кластеризацию с помощью K-Means и DBSCAN, сравните результаты разных подходов и параметров
- Оцените качество кластеризации с помощью метода локтя, силуэтного коэффициента и интерпретируемости полученных групп
- Опишите выделенные сегменты: дайте каждому сегменту понятное название и сформулируйте его продуктовый портрет
- Подготовьте бизнес-рекомендации: предложите, как адаптировать личный кабинет, коммуникации и сценарии взаимодействия для каждого сегмента
- Финализируйте код в Jupyter Notebook и подготовьте итоговую аналитическую презентацию
## Материалы для выполнения проекта
- Материалы для выполнения проекта можно найти внизу страницы.
- Датасет teacher_activity_logs.csv — лог активности 1 500 учителей за 45 дней: вход, работа с домашними заданиями, материалами, вебинарами, оценками и расписанием. В логе есть «шумные» тестовые/парсерские аккаунты и пропуски в части записей — их нужно выявить и отфильтровать на этапе предобработки, прежде чем строить сегменты.
